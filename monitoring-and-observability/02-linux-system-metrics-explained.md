# 02 – Linux System Metrics Explained

## Purpose
System metrics describe **how a machine is behaving internally**.
DevOps engineers use these metrics to detect stress, degradation, and early signs of failure.

---

## What Are System Metrics?

System metrics are measurements related to:
- CPU usage
- Memory consumption
- Disk usage
- System load

They represent **resource pressure**, not application logic.

---

## Why Metrics Matter in DevOps

Metrics help DevOps engineers:
- Detect abnormal behavior early
- Understand system limits
- Prevent outages caused by resource exhaustion

Without metrics, failures appear sudden and unexplained.

---

## Commonly Observed Metrics

The most critical Linux metrics are:
- CPU utilization
- Available memory
- Disk space usage
- Load average

These metrics are monitored continuously in production systems.

---

## Real DevOps Scenario

Problem: Application becomes slow  
Metrics show: High load average and memory pressure  
Action: Scale resources or optimize workload before failure

---

## Key Takeaway
System metrics provide visibility into **system health** and help teams act before incidents occur.
